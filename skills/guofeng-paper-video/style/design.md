# 国风纸片动画 · 视觉 DNA

这份文档描述这套风格**长什么样、怎么动**，跟任何具体片子（守株待兔 / 江雪）无关。做新片前，先让 AI 读这份 + `palette.md`，把风格吃进去，再动手分镜。

## 一句话

把一个画面**拆成一张张白描纸片**，每张单独入场、呼吸、位移，叠在一张墨线山水背景上，点一枚朱红印章——像一幅会动的手工拼贴。

## 六个视觉支柱

1. **纸片拼贴**：画面主体（人 / 动物 / 器物 / 山 / 云）各是一张透明背景白描 PNG，独立成层。不是一整张图在动，是一叠纸片各飘各的。
2. **墨线白描**：所有元素走白描线稿——细墨线勾边、淡赭石/墨色晕染。不要写实照片、不要厚涂、不要 3D。
3. **暖纸材质**：底色是暖米白纸（`#efe2c6` 一带），带纸纹；纸片边缘**撕裂毛边**（不规则多边形 clipPath），叠一层**硬纸投影**（亮边 + 暖褐暗影）。
4. **朱红印章**：唯一的高饱和色是朱红（`#8f2019`）。用在圆/方印章、楷体大字（"咚""完"）、关键标签。面积小、位置刁，起"敲一下"的作用。
5. **横版留白构图**：1920×1080；背景满幅 + 缓推镜；主体纸片错落偏置、不居中堆叠；左上角贴撕边纸标签，底部居中走字幕。
6. **中文靠代码渲染**：所有文字用系统字体现渲染（宋体 / 楷体 / 苹方），**不让 AI 把字画进图里**——这是"零错字"的来源，也是这套风格相对 AI 生图的核心优势。

## 运动语言

- **入场**：纸片从侧下方带回弹地滑入（spring），同时从略小放大到位。主角滑得远、回弹明显；远景几乎在原地淡入。
- **待机**：入场后每张纸片做极缓慢的正弦"呼吸"浮动（不同纸片相位错开，避免同步）。
- **分层视差**：靠"角色"拉开层次——主角（primary）动得多，中景（secondary）中等，远景（tertiary）几乎不动。**这一条是整套质感的关键**，别让所有纸片一样地动。
- **镜头**：背景大图缓慢推近（几帧内 scale 1.02→1.05 + 轻微平移），给静止画面一点呼吸。
- **转场**：一块朱红撕纸从画面横扫而过，接下一镜。
- **卡点**：印章落下、物体相撞这类"重音"，配一声音效卡在动作帧上。

## 字体

| 用途 | 字体 |
|---|---|
| 标签大标题 | 宋体 `Songti SC` / `STSong` |
| 印章 / 楷体重字 | 楷体 `STKaiti` / `Kaiti SC` |
| 字幕 / 小注 / 正文 | 苹方 `PingFang SC` |

> macOS 自带这三种。Windows / 云端渲染要装上，或换成本机等价中文字体，否则中文 fallback 走形，"零错字"优势就没了。

## 明确禁用

写实照片、厚涂 CG、3D 渲染、发光 / 霓虹 / 赛博、扁平 emoji 贴纸、塑料渐变、多种高饱和强调色同台、让 AI 把中文标题直接生进图里。
