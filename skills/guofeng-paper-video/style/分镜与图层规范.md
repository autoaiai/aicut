# 分镜与图层规范

从"一首诗"到"一条片"，中间这层是：**分镜表 → 每镜的纸片清单 → 每张纸片的图层参数**。这份讲参数怎么填。

## 时间轴

- 30 fps。**帧数 = 秒 × 30**。总时长是一个常量（示例 `IDIOM_SHOU_ZHU_DAI_TU_DURATION = 765` = 25.5 秒）。
- 一条片 = 若干镜，每镜一个 `<Sequence from={起始帧} durationInFrames={帧数}>`。一镜默认 **120 帧（4 秒）**，落点镜可长些。
- 每个 Sequence 建议 `premountFor={30}`：提前 30 帧预挂载，避免入场卡顿。

## 一镜的构成

1. **背景**：`<FieldPlate src={plate} camera={clamp(frame,[0,120],[0,1])} />`——camera 从 0 缓推到 1。荒芜镜加 `mood="dry"`。
2. **纸片**：若干 `<PaperCollageLayer spec={...} />`，spec 见下。
3. **标签**（可选）：`<PaperTag title="..." note="..." from={帧} x y width />`——贴一句说明。
4. **字幕**：`<StoryCaption from={帧}>这一镜的旁白</StoryCaption>`——底部居中，跟配音对齐。
5. **重音**（可选）：印章 / 楷体大字 / 特效，配一声音效。

## 图层参数 `PaperCollageLayerSpec`

每张纸片一份（类型定义在 [`src/components/PaperCollageLayer.tsx`](../src/components/PaperCollageLayer.tsx)）：

| 字段 | 类型 | 意思 |
|---|---|---|
| `id` | string | 唯一名 |
| `src` | string | `staticFile()` 的纸片路径 |
| `x` `y` | number | 左上角落位 |
| `width` | number | 宽（高自动） |
| `delay` | number | 第几帧入场（同镜内错开，别一起进） |
| `role` | `primary`/`secondary`/`tertiary` | **决定运动幅度**，见下 |
| `direction` | `-1`/`1` | 入场从左(-1)还是右(1)滑入 |
| `zIndex` | number | 叠放层级 |
| `opacity?` | number | 整体透明（远景压淡用） |
| `flipX?` | boolean | 左右翻转 |
| `phase?` | number | 呼吸相位偏移（避免多片同步浮动） |

### role 决定层次（关键）

| role | 位移 | 起始缩放 | 入场时长 | 给谁 |
|---|---|---|---|---|
| `primary` | 大（104px） | 0.84 | 42 帧 | 这一镜的主角 |
| `secondary` | 中（72px） | 0.90 | 36 帧 | 中景、配角 |
| `tertiary` | 小（44px） | 0.95 | 30 帧 | 远景、陪衬 |

主角给 `primary`、远景给 `tertiary`，层次感是这一条自动拉开的。**别把所有纸片设成同一个 role**——那样画面会"整体平移"，失去拼贴的纵深。运动（入场回弹、呼吸浮动、纸投影）全在 `PaperCollageLayer` 里算好，你只填这张"参数单"。

### 一个真实 spec（示例片里的守株农夫，节选）

```tsx
const waiting: PaperCollageLayerSpec = {
  id: 'farmer-waiting',
  src: staticFile(layer('farmer-waiting')),
  x, y, width,
  delay: 5,
  role: 'primary',
  direction: -1,
  zIndex,
};
// 用：<PaperCollageLayer spec={waiting} />
```

## 音频编排（`StoryAudio`）

- **环境音**打底：一条 ambient `loop`、低音量（~0.12）铺全片。
- **配音**：每句旁白一个 `vo-0x.wav`，用 `<Sequence from={该镜起始帧}>` 卡在对应镜，跟字幕对齐。**配音用 MiniMax 生成**（见 [prompts/03-配音脚本.md](prompts/03-配音脚本.md)）。
- **音效**：转场配 `paper-whoosh`（~0.52），撞击 / 落点配 `thump` / `lock` / `magnetic` 卡在动作帧。
- 素材放 `public/audio/{slug}/`（片子专属）+ 复用的环境音单独放公共目录。**换素材时音频目录整个别落下**，否则 render 报错找不到文件。
