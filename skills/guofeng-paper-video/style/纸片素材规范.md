# 纸片素材规范

一条片的视觉料 = 一张背景大图 + 若干张纸片。这份讲怎么把它们做出来、放哪、怎么命名。

## 两类素材

### 1. 背景大图 field-plate
- 一张满幅墨线山水 / 场景图，作为最底层（`FieldPlate` 组件用）。
- 尺寸 ≥ 1920×1080（组件会放大到 1980×1140 留推镜余量）。
- 可带纸纹、淡赭染。**不要**把主体人物 / 动物画死在背景里——主体要单独做成纸片，才能各自动。
- 放 `public/style/{slug}/field-plate.png`。

### 2. 纸片 layers
- 每张纸片 = **一个语义单位**：一个人、一只动物、一件道具、一座山、一团云。
- **透明背景 PNG**、白描线稿风、主体居中留边、长边 ≥ 1000px。
- **不带写实阴影**（投影由代码 `drop-shadow` 统一加，自带阴影会脏）。
- **不带文字**（文字交给代码，纸片上写字等于把"零错字"优势丢了）。
- 放 `public/style/{slug}/layers/`，语义英文短名：`farmer-working.png` / `rabbit-fallen.png` / `stump.png`。同一角色多个状态就多做几张（`farmer-holding` / `farmer-waiting`）。

## 生成 → 抠边流程

1. **生图**：用即梦 / Lovart / MJ 出白描线稿。提示词模板见 [prompts/02-生成纸片.md](prompts/02-生成纸片.md)（要点：白描、线稿、浅色底、单个主体、无文字、无写实光影）。
2. **抠透明底**：AI 出的图常带底色 → 用去背工具（remove.bg / 即梦自带去背 / PS）抠成透明 PNG。边缘干净、保留白描线。
3. **验收**：贴到深色背景上看——描边是否连续、有没有残留底色、主体是否完整。
4. **命名归位**：按上面的命名放进 `public/style/{slug}/layers/`。

## 一条片大概要几张

一镜通常 2–5 张纸片（1 主角 + 1–2 中景 + 1–2 远景陪衬）。整条 5–6 镜的片，10–20 张纸片 + 1 张背景够用。宁可复用，别每镜全新。
