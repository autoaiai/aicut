# 提示词 · 配音脚本 + 编排

## 1. 整理配音脚本

```
把分镜表里每镜的旁白，整理成一份配音脚本：
每句一行，按镜顺序编号 vo-01、vo-02……
语气 {{沉稳讲述 / 轻松 / 古意}}，语速适中，句子短、上口。
```

## 2. 生成配音（MiniMax）

用 **MiniMax** 语音把每句合成一条 wav：`vo-01.wav … vo-0n.wav`，放 `public/audio/{{slug}}/`。
（MiniMax 的具体调用按你手上的方式来，Agent 不代管密钥。）

## 3. 接进时间线（对 Claude 说）

```
配音已放在 public/audio/{{slug}}/，环境音和音效放在公共音频目录。
在这条片的 StoryAudio 里：
- ambient 环境音 loop、低音量(~0.12)铺全片
- 每条 vo-0x 用 Sequence 卡在对应镜的起始帧，跟字幕对齐
- 转场配 paper-whoosh，撞击/落点配 thump/lock 卡在动作帧
render 前确认音频文件都在，别漏。
```

音频编排的字段细节见 [../分镜与图层规范.md](../分镜与图层规范.md#音频编排storyaudio)。
