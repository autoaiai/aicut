# 提示词 · 生成白描纸片

## 给绘图工具（即梦 / Lovart / MJ）

> 用 **Codex** 可以直接让它生图（自带图像生成），省去外部工具；用 **Claude Code** 则要另接一个图片生成 API，或者用下面的提示词喂即梦 / Lovart / MJ 生完再放进来。

按分镜的纸片清单，一张一张出。中文模板（替换 `{{}}`）：

```
国风白描线稿，{{主体，如"一个弯腰锄地的农夫"}}，
单个主体、居中、完整，纯色浅背景便于抠图，
细墨线勾边、淡赭石晕染，无写实光影、无阴影、无文字、无边框，
传统工笔白描风格。
```

英文（喂 MJ / nanobanana）：

```
Traditional Chinese ink-outline (baimiao) line drawing of {{subject}},
single subject, centered, full body, plain light background for easy cutout,
fine ink linework with light ochre wash, no realistic shading, no cast shadow,
no text, no border, gongbi baimiao style.
```

背景大图把主体换成场景：`{{墨线山水 / 田野 / 庭院}}，满幅，留出主体活动的空间`。

## 抠边（对 Claude 说 / 手动）

```
把生成的纸片抠成透明背景 PNG，去掉底色，保留白描线，
主体居中留边，按语义英文名存到 public/style/{{slug}}/layers/。
背景大图存 public/style/{{slug}}/field-plate.png。
```

（抠图本身用 remove.bg / 即梦去背 / PS，这一步 Agent 代跑不了，留给你手动。）

要点重申：**透明底、白描、无文字、无写实阴影、长边 ≥ 1000px**。细则见 [../纸片素材规范.md](../纸片素材规范.md)。
